# 🛡️ Host Security Auditor (Go + Local LLM SOC Pipeline)

Модульная система аудита защищенности хостов на языке **Go (Golang)** с интеграцией с локальной языковой моделью (**TextGen WebUI / Ollama / llama.cpp**), разработанная в точном соответствии с архитектурной спецификацией.

---

## 📐 Архитектурный конвейер (Pipeline Architecture)

Языковая модель выступает **исключительно** в роли интеллектуального интерпретатора и переводчика контекста: она полностью изолирована от «угадывания» фактов и оперирует только тем датасетом, который подготовил конвейер сбора данных на Go.

```
[ Веб-интерфейс / CLI Клиент (ПК безопасника) ]
                      │
                      ▼
[ ЯДРО СИСТЕМЫ (Оркестратор на Go) ]
  • Управление профилями сканирования (Fast / Standard / Aggressive)
  • Валидация целей (IP / CIDR / Домен)
  • Очередь и запуск процессов (Subprocess Worker)
                      │
                      ▼
[ МОДУЛЬ СКАНИРОВАНИЯ (Nmap) ]
  • Флаги под профиль (-sS/-sT, -sV, -O, -sC)
  • Встроенные скрипты сбора CVE (--script=vulners)
  • Вывод в машиночитаемый stdout (-oX -)
                      │ (Сырой stdout + XML-структура)
                      ▼
[ МОДУЛЬ НОРМАЛИЗАЦИИ И СВЕДЕНИЯ ДАННЫХ ]
  • Извлечение открытых портов, ОС, баннеров служб
  • Структурирование найденных NSE скриптами CVE и оценка CVSS
  • Фильтрация сетевого шума и сбор единого контекстного JSON
                      │ (Строгий JSON-манифест инцидента)
                      ▼
[ МОДУЛЬ СИНТЕЗА И ОТЧЕТНОСТИ (LLM) ]
  • Локальный инференс (TextGen WebUI / Ollama / LM Studio)
  • Строгий System Prompt (RAG без внешнего поиска, защита от галлюцинаций)
  • Цветовая классификация: 🔴 Красный / 🟡 Желтый / 🟢 Зеленый
  • Формирование бизнес-сводки и рекомендаций по защите для директора компании
                      │
                      ▼
[ Финальный интерактивный отчет и экспорт в Markdown ]
```

## 🚀 Быстрый старт

### 1. Запуск через пакетный файл (Windows)
Просто дважды кликните по файлу `run.bat` или выполните в PowerShell:
```powershell
cd D:\GoProjects\host-security-auditor
.\run.bat
```
Сервер автоматически запустится на `http://localhost:8080` и откроет страницу в браузере.

### 2. Запуск через `go run`
```powershell
go run .\cmd\auditor
```

### 3. Быстрый CLI-тест со стендом из PDF (без браузера)
```powershell
.\auditor.exe -target 192.168.10.15 -profile aggressive -demo
```

## ⚙️ Настройка локальной нейросети (TextGen / Ollama)

В правом верхнем углу интерфейса доступно окно **⚙️ Настройки**:

### Вариант А: TextGen WebUI (Oobabooga)
1. Запустите TextGen WebUI с параметром `--api` (или включите расширение `openai` во вкладке Session).
2. По умолчанию TextGen поднимает OpenAI-совместимый сервер на `http://127.0.0.1:5000/v1`.
3. В настройках веб-панели аудитора укажите:
   - **Провайдер:** `OpenAI-совместимый`
   - **API Эндпоинт:** `http://127.0.0.1:5000/v1`
   - **Модель:** `qwen2.5` (или имя загруженной модели)
   - Нажмите кнопку **«Проверить связь с TextGen»**.

### Вариант Б: Ollama
1. Запустите `ollama run qwen2.5:7b` (или `llama3.1:8b`).
2. В настройках веб-панели аудитора укажите:
   - **Провайдер:** `Ollama Native API` (или OpenAI-совместимый)
   - **API Эндпоинт:** `http://127.0.0.1:11434/v1` или `http://127.0.0.1:11434/api/chat`
   - **Модель:** `qwen2.5:7b`

## 🛡️ Профили сканирования

| Профиль | Флаги Nmap | Назначение |
| :--- | :--- | :--- |
| **Экспресс (Fast / Discovery)** | `-sS -T4 --top-ports 100 -n` | Быстрая инвентаризация активных портов без углубления в детали. Полезно для массового обзора. |
| **Базовый (Standard)** | `-sV --version-light -O -T3` | Определение операционной системы, базовых версий служб без тяжелых скриптов. |
| **Глубокий (Aggressive / Audit)** | `-sV --version-all -sC --script=vulners -O -T3 --top-ports 1000` | Максимальное распознавание служб (WordPress, Apache, SSH, SMB), сопоставление с базами CVE через Vulners, детекция ОС. |

> **Примечание по правам доступа:** В Windows для `-sS` и `-O` требуются права администратора и установленный Npcap. Если программа запущена без повышенных привилегий, ядро автоматически выполняет fallback на **TCP Connect (`-sT`)**, предотвращая аварийное завершение.

## 🔒 Контроль галлюцинаций LLM

В модуль интеграции с нейросетью зашит строгий системный промпт SOC-аналитика:
1. **Запрет на выдумывание:** Использовать ТОЛЬКО уязвимости (CVE) и версии, явно переданные в нормализованном JSON.
2. **Устаревшие службы без CVE:** Относятся строго к **ЖЕЛТОМУ** уровню с пометкой *«требует плановой проверки/обновления»*.
3. **Цветовая дифференциация:**
   - 🔴 **КРАСНЫЙ (Критично):** Подтвержденные CVE с высоким CVSS (RCE, захват контроля), опасные открытые порты баз данных/SMB наружу.
   - 🟡 **ЖЕЛТЫЙ (Предупреждение):** Сервисы удаленного доступа (SSH, RDP), риски подбора паролей (брутфорс), отсутствие шифрования.
   - 🟢 **ЗЕЛЕНЫЙ (Безопасно):** Штатные сетевые службы без зафиксированных проблем.
4. **Практические действия:** Каждому пункту дается понятное действие для руководства и системных администраторов (обновление плагина, изоляция правилом файрвола, 2FA/VPN).

```
host-security-auditor/
├── cmd/
│   └── auditor/

│   ├── config/

│   ├── orchestrator/
│   │   ├── validator.go         # Валидация целей (IPv4, IPv6, CIDR, Domain)
│   │   ├── profiles.go          # Профили сканирования (Fast, Standard, Aggressive)
│   │   ├── queue.go             # Потокобезопасное хранилище и статусы задач
│   │   └── worker.go            # Оркестратор: Nmap -> XML -> JSON -> LLM -> Report
│   ├── scanner/
│   │   ├── profile.go           # Определения и флаги профилей аудита

│   ├── normalizer/
│   │   ├── nmap_xml.go          # Структуры для декодирования XML Nmap
│   │   ├── manifest.go          # Строгий компактный JSON-манифест инцидента
│   │   ├── parser.go            # Нормализатор: извлечение портов, ОС, скриптов vulners и фильтрация шума
│   │   └── parser_test.go       # Юнит-тесты нормализатора на реальном стендовом XML
│   ├── llm/
│   │   ├── prompt.go            # Строгий System Prompt SOC-аналитика из PDF
│   │   └── client.go            # Универсальный клиент (TextGen/OpenAI API + Ollama API)
│   └── web/
│       ├── server.go            # REST API сервер с внедрением статики (go:embed)
│       └── static/
│           ├── index.html       # Интерактивный веб-дашборд SOC-аналитика
│           ├── style.css        # Темная тема в стиле Security Operations Center
│           └── app.js           # Клиентская логика, live-валидация, Markdown-рендер
├── testdata/
│   └── sample_vuln_host.xml     # Стендовый XML файл с уязвимостями
├── config.json                  # Конфигурационный файл
├── run.bat                      # Пакетный файл запуска в 1 клик для Windows
├── go.mod                       # Модуль Go
└── README.md                    # Полная документация
```
